# Jaimin George - Digital Marketing Specialist Portfolio

A modern, responsive, high-converting digital marketing specialist portfolio website built with HTML5, Tailwind CSS, Font Awesome, and Google Fonts.

## Project Structure

```
jaimin-george-portfolio/
├── index.html        # Main landing page with all sections and scripts
└── README.md         # Project documentation
```

## Features Included

- **Hero Section**: High-converting title, value proposition, call-to-actions, and strategy matrix showcase.
- **Services (8 Core Offerings)**: SEO, Google Ads, Social Media Marketing, Meta Ads, Content Marketing, Website Development, Google Analytics, and Email Marketing.
- **Why Choose Me**: Execution framework (`PLAN • CREATE • ANALYZE • GROW`), metrics (100+ clients, 150+ campaigns, 5+ years), and key differentiators.
- **About Me**: Professional portrait, story, and core values.
- **Portfolio & Case Studies**: 4 measurable ROI/KPI cards with conversion statistics.
- **Industries Served**: E-commerce, Real Estate, Education, Hospitality, Healthcare, Startups, and Local Business.
- **Transparent Pricing**: 3 plans (Starter, Growth [Most Popular], Premium) with features checklist.
- **Client Testimonials**: Verified client reviews with star ratings.
- **Blog Section**: Marketing insights and guides.
- **Interactive Contact Form & Details**: Working form with animated toast notification and direct contact links.
- **Fully Responsive**: Mobile menu toggle and seamless navigation across all device viewports.
